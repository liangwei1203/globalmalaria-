# Code for The changing landscape of imported malaria in the area of elimination: a seven-decade global analysis
This repository contains all R code and aggregated country-level datasets to reproduce the analyses presented in our Nature Article:
**The changing landscape of imported malaria in the area of elimination: a seven-decade global analysis**

## Project overview
This study characterizes the spatiotemporal dynamics of global imported malaria over seven decades, quantifies clustered secondary transmission, identifies key demographic shifts among migrant cases, and projects future burdens under SSP socioeconomic scenarios.

## Environment & dependencies
- R version: 4.5.1
- Required R packages:
tidyverse, lme4, randomForest, survival, brglm2, mgcv, igraph

> Full package versions are reported in `99_session_info.R` for reproducibility.
